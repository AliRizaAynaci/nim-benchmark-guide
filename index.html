01 — Kurulum Rehberi

3 adımda NIM + OpenCode kurulumu

Toplam süre: yaklaşık 5 dakika (tahmini). Gerekenler: bir terminal, bir tarayıcı ve e-posta adresin. Kredi kartı veya ödeme bilgisi gerekmez — NVIDIA API key almak için telefon doğrulaması zorunludur.

01

NVIDIA Build hesabı aç ve API Key al

~2 dk

build.nvidia.com adresine git ve sağ üstten "Login" ile bir NVIDIA hesabı oluştur. Ardından herhangi bir model sayfasına girip "Get API Key" düğmesine bas.

Kredi kartı gerekmez ama telefon doğrulaması ZORUNLUDUR. API key alabilmek için NVIDIA, numaranı SMS ile doğruluyor. Türkiye (+90) gibi bazı numaralarda doğrulama adımı sorun çıkabildiği görülüyor; doğrulama tamamlanamazsa NVIDIA forumundan manuel onay isteyebilirsin.

  • →API Key nvapi- önekiyle başlar; bir kez gösterilir, hemen kopyala.
api-key.txt 
nvapi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx  ← kendi anahtarın

✓ Anahtarı kaybedersen hesabından "Regenerate" ile kolayca yeni bir tane oluşturabilirsin.

02

Anahtarı terminalde ortam değişkeni olarak tanıt

~1 dk

Komut işletim sistemine göre değişir — aşağıdaki sekmelerden kendine uygun olanı seç. macOS/Linux'ta export NVIDIA_API_KEY='nvapi-...' ile tanımlayıp .zshrc'ye ekliyorsun; Windows'ta PowerShell ile setx komutu kalıcı atama yapıyor.

terminal — bash / zsh 
# 1) Mevcut terminal oturumun için:
export NVIDIA_API_KEY='nvapi-xxxxxxxxxxxxxxxxxxxxxxxx'

# 2) Kalıcı olması için .zshrc'ye ekle, sonra yeniden yükle:
echo "export NVIDIA_API_KEY='nvapi-xxxxxxxxxxxxxxxxxxxxxxxx'" >> ~/.zshrc
source ~/.zshrc
powershell — windows 
# 1) Kalıcı ortam değişkeni olarak ata (yeni pencerelerde geçerli):
setx NVIDIA_API_KEY 'nvapi-xxxxxxxxxxxxxxxxxxxxxxxx'

# 2) setx mevcut pencereyi etkilemez; pencereyi kapat,
#    yeni bir PowerShell aç ve doğrula:
echo $env:NVIDIA_API_KEY

✓ Anahtarını kimseyle paylaşma ve git deposuna commit etme — önüne düşen herkes senin NIM deneme kotanı kullanabilir.

03

OpenCode'u kur ve modelini seç

~2 dk

OpenCode'u kur, bir proje klasörüne gir ve opencode komutuyla başlat. TUI içinde /model yazınca NVIDIA sağlayıcısına ait modelleri filtreleyip seçebilirsin — hepsi bu.

terminal 
curl -fsSL https://opencode.ai/install | bash
mkdir projem && cd projem
opencode  # TUI açılır; /model ile NIM modelini seç

# Hangi NVIDIA modellerinin listelendiğini TUI dışında görmek için:
opencode models | grep -i nvidia

✓ Windows kullanıyorsan OpenCode kurulum paketi için opencode.ai'ye bak; kurulumdan sonraki /model adımı her platformda aynı.

04 — Sınırlar ve Limitler

Ücretsiz erişimin sınırları

NVIDIA, geliştiricilere API Trial Terms kapsamında sınırlı, kredi bazlı ücretsiz deneme erişimi sunuyor. Sabit limit sayıları şartlarda yayınlanmıyor — bu bölüm neyin doğrulanabileceğini ve neyin doğrulanamadığını açıkça işaretliyor.

NVIDIA NIM nedir?

NVIDIA, üçüncü taraf açık ağırlıklı modelleri kendi altyapısında host eder ve OpenAI uyumlu tek bir API (integrate.api.nvidia.com/v1) ile sunar. Amaç modelleri geliştiricilere tanıtmak; yoğun üretim yükü taşıyan bir hizmet olarak tasarlanmamıştır. Bu projede 11 metin LLM'si katalog üzerinden doğrulandı (erişim: 10.10.2026).

Limitler nereden doğrulanır? 40 RPM · DOĞRULANAMADI

API Trial Terms, kullanımı "NVIDIA tarafından tanımlanan kullanım limitleri"ne ve deneme kredilerine bağlıyor; şartlarda sabit bir istek/dakika (RPM) sayısı yayınlanmıyor. Topluluk yazılarında sıkça "40 RPM" geçer — bu sayı bu projede doğrulanamadı. Güncel kotanı NVIDIA panelindeki kullanım ekranından ve API yanıtlarındaki limit header'larından izleyebilirsin; limit hatası alırsan kısa bir mola ver.

OpenCode'un rolü ne?

OpenCode, terminalde çalışan açık kaynak bir kod asistanı. NVIDIA_API_KEY tanımlıysa NIM modellerini listeler, /model ile seçersin. NIM erişimi (sunucu tarafı) ile OpenCode yapılandırması (istemci tarafı) ayrı konulardır: bir modelin katalogda olması, OpenCode'ta her senaryoda sorunsuz çalışacağını garanti etmez — tool-calling ve reasoning davranışları modele göre değişir. Karşındaki şey "bedava sınırsız abonelik" değil; limitleriyle birlikte gerçek bir deneme erişimi.
